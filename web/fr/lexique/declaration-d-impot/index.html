Déclaration d’impôt

Mis à jour le 26 novembre 2026

Dans la déclaration d’impôt, vous déclarez vos revenus de l’année de revenus. Vous devez, en principe, rentrer une déclaration d’impôt chaque année.

Si votre situation fiscale est plutôt simple, vous recevrez probablement une proposition de déclaration simplifiée ; vous ne devez alors, en principe, plus rentrer de déclaration. Si vous ne recevez pas de proposition, vous devez rentrer une déclaration. En ligne, vous pouvez le faire via MyMinfin (Tax-on-web), où vos données sont en grande partie pré-remplies. Les personnes mariées et les cohabitants légaux remplissent en principe une déclaration commune (voir imposition commune).

Le SPF Finances publie les délais chaque année ; ils diffèrent selon que vous rentrez la déclaration sur papier ou via MyMinfin et selon que vous avez des revenus spécifiques. Une déclaration rentrée en retard ou pas du tout peut entraîner une amende et/ou un accroissement d’impôt, et le SPF peut alors établir l’impôt d’office.

Le SPF traite la déclaration pour calculer l’impôt et vous envoie ensuite un avertissement-extrait de rôle. Si vous constatez une erreur, une déclaration rentrée en ligne peut être corrigée une fois via MyMinfin dans le délai indiqué par le SPF ; ensuite, vous prenez contact avec votre service compétent.
