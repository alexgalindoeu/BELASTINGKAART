Thème

Aperçu

Tant que toutes les règles ne sont pas confirmées, le widget indique que le résultat suivra ; aucun salaire net n’est calculé.

Code à copier

Collez ce code dans votre page, à l’endroit où le widget doit apparaître. Le lien sous le cadre fait partie du code et doit rester visible.

Facultatif : laisser le cadre ajuster sa hauteur

Le widget transmet uniquement sa hauteur à la page qui l’affiche. Ajoutez ce script une fois à votre page pour que le cadre s’adapte ; sans script, la hauteur du code s’applique.

<script>
addEventListener("message", function (e) {
  if (e.origin !== "https://belastingkaart.be" || !e.data || e.data.type !== "belastingkaart:height") return;
  document.querySelectorAll('iframe[src^="https://belastingkaart.be/"]').forEach(function (f) {
    if (f.contentWindow === e.source) f.style.height = Math.min(Math.max(+e.data.height || 0, 240), 1200) + "px";
  });
});
</script>

Conditions d’utilisation

  • Gratuit pour tout site, sans inscription.
  • Gardez la mention : le lien vers Belastingkaart sous le cadre reste visible et inchangé.
  • Ne présentez pas le widget comme un outil officiel des pouvoirs publics ni comme un conseil fiscal.

Belastingkaart peut modifier l’apparence du widget ou y mettre fin. Le calcul est expliqué dans la méthodologie.

Questions fréquentes

Combien coûte le widget ?

Rien. Il est gratuit pour tout site, y compris commercial, et aucune inscription n’est nécessaire.

Qu’affiche le widget actuellement ?

Un formulaire simple et le message indiquant que le résultat s’affichera lorsque toutes les règles seront confirmées, avec la liste de ces règles. Aucun salaire net n’est affiché.

Le widget collecte-t-il des données ?

Non. Ce que les visiteurs saisissent reste dans leur navigateur. Il n’y a ni cookies, ni publicités, ni traceurs.
