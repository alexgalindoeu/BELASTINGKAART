De simulator op je eigen website

Bijgewerkt op 26 november 2026

Kopieer een stukje code en je bezoekers zien de bruto-nettosimulator van Belastingkaart op je website. Gratis, zonder cookies en zonder advertenties.

Voorbeeld

Code om te kopiëren

Plak deze code in je pagina, waar de widget moet verschijnen. De link onder het kader hoort bij de code en moet zichtbaar blijven.

Optioneel: het kader zijn hoogte zelf laten aanpassen

De widget stuurt alleen zijn hoogte naar de pagina die hem toont. Voeg dit script één keer toe aan je pagina om het kader te laten meegroeien; zonder script geldt de hoogte uit de code.

<script>
addEventListener("message", function (e) {
  if (e.origin !== "https://belastingkaart.be" || !e.data || e.data.type !== "belastingkaart:height") return;
  document.querySelectorAll('iframe[src^="https://belastingkaart.be/"]').forEach(function (f) {
    if (f.contentWindow === e.source) f.style.height = Math.min(Math.max(+e.data.height || 0, 240), 1200) + "px";
  });
});
</script>

Gebruiksvoorwaarden

  • Gratis voor elke website, zonder registratie.
  • Laat de vermelding staan: de link naar Belastingkaart onder het kader blijft zichtbaar en ongewijzigd.
  • Stel de widget niet voor als een officiële overheidstool of als fiscaal advies.

Belastingkaart kan het uitzicht van de widget aanpassen of hem stopzetten. De berekening wordt uitgelegd in de methodologie.

Veelgestelde vragen

Wat kost de widget?

Niets. Hij is gratis voor elke website, ook commerciële, en je hoeft je niet te registreren.

Wat toont de widget nu?

Een eenvoudig formulier en de melding dat het resultaat volgt zodra alle regels bevestigd zijn, met de lijst van die regels. Er wordt geen nettoloon getoond.

Verzamelt de widget gegevens?

Nee. Wat bezoekers invullen, blijft in hun browser. Er zijn geen cookies, geen advertenties en geen trackers.
